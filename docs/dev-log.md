## Phase 3: content 正規化 + fuzzy matching による主科目推定（2026-09-27）

`mf analyze3`（`phase3.py`）。LLM・embedding 未使用。RapidFuzz（ローカル）を追加。評価はローリング（取引日より前のデータのみ検索対象）、ラベルは主科目（相手科目のうち最大額）。

### 正規化方式（元の tx_content は変更せず派生値として計算）

raw / n1 NFKC+casefold+空白整理 / n2 +記号を空白に / n3 +空白除去 / n4 +6桁以上の数字をマスク / n5 +4桁以上の数字と日付をマスク（短い数字は全方式で保持）

- distinct content 1,839 → n3 で 1,797 → n4 で 1,738（正規化で統合される表記揺れは少ない）
- fuzzy 用の正規化は FY2022+2023 の正解件数で選択 → n4

### FY2024 比較（主科目, n4, ratio）

|---|---:|---:|---:|

- normalized exact の追加分: FY2022 +6（100%）/ FY2023 +21（85.7%）/ FY2024 +16（62.5%）
- fuzzy（ratio）追加分の accuracy は ≥80 で 50〜68%。WRatio はさらに低い（38〜59%）
- FY2024 の候補なし 22.5%（complex 75件を含む）
